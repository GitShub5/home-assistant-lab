# Home Assistant Smart Home Lab

## Overview

This project documents my personal Home Assistant smart home lab running in a virtualized homelab environment.  
The goal of this lab is to gain hands-on experience with smart home technologies, automation workflows, device integrations and modern self-hosted infrastructure solutions.

The environment is continuously expanded and used to test automations, monitoring solutions and connected IoT devices in a practical setup.

---

## Technologies Used

- Home Assistant
- Proxmox VE
- Virtual Machines
- Zigbee
- Matter
- Amazon Alexa
- IoT Devices
- Smart Home Automations
- Network-based Device Integrations

---

## Features Implemented

- Home Assistant running as a virtual machine on Proxmox
- Device monitoring and management
- Smart home dashboard customization
- Automation workflows
- Notification and alert setup
- Integration of smart home devices and sensors
- Voice assistant integration with Amazon Alexa
- Zigbee and Matter device integrations
- Remote access setup for secure management
